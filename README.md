# LeetCode Journey — 30 Days, 50 Problems

Learning problem-solving in Python from scratch, one pattern at a time.
Following a structured 30-day roadmap (Python refresher → arrays/strings →
hashing/sliding window → recursion/trees → DP/graphs).

## Why this repo exists

Tracking daily progress publicly to build consistency and show real
problem-solving growth over time — not just final answers, but the
reasoning behind them.

## Structure

```
leetcode-journey/
├── README.md
├── PROGRESS.md          # tracker: problem, pattern, status, notes
└── solutions/
    ├── day01_*.py
    ├── day02_*.py
    └── ...
```

Each solution file includes:
- The problem name/link
- My approach in plain words (before the code)
- The solution
- Time & space complexity

## Roadmap

| Phase | Days | Focus |
|---|---|---|
| 0 | 1–3 | Python refresher (loops, data structures, Big O intuition) |
| 1 | 4–10 | Arrays, Strings, Two Pointers |
| 2 | 11–17 | Hashing, Sliding Window, Stacks/Queues |
| 3 | 18–24 | Recursion, Linked Lists, Trees |
| 4 | 25–30 | Dynamic Programming basics, Graphs, Review |
